# Mind Studio · סטודיו המשחקים

אפליקציה מאספת למשחקים. מתחברים פעם אחת בדף הראשי, וכל משחק שנפתח משם כבר מחובר לאותו חשבון. לכל משחק יש מטבעות, חנות והתקדמות משלו.

| קטגוריה | משחק | קובץ |
|---|---|---|
| חשיבה | סודוקו חכם | `../Web/index.html` (גרסת הרשת של הסודוקו) |
| חשיבה | ציור נסתר | `games/nonogram.html` |
| חשיבה | פיצוח הצופן | `games/codebreaker.html` |
| חשיבה | גן הפנסים | `games/lights.html` |
| חשיבה | זיכרון | `games/memory.html` |
| לוח וקלפים | שחמט (מול המחשב, 3 רמות) | `games/chess.html` |
| לוח וקלפים | דמקה ישראלית (מול המחשב, 3 רמות) | `games/checkers.html` |
| לוח וקלפים | ארבעה צבעים (קלפים מול 1–3 יריבים) | `games/colors.html` |
| פעולה | כביש מהיר (התחמקות ממכוניות) | `games/racer.html` |
| פעולה | ריצת הנתיבים (שלושה נתיבים, קפיצה והחלקה) | `games/runner.html` |

## איך מריצים
```
powershell -ExecutionPolicy Bypass -File Hub\serve.ps1
```
ואז פותחים את http://localhost:8780/Hub/

השרת מגיש את כל תיקיית הפרויקט, כך שהמאספת והסודוקו נמצאים באותה כתובת ולכן חולקים את אותה התחברות.

## שליטה במשחקי הפעולה
חצים או WASD במקלדת, ארבעה כפתורים מתחת למסך (◀ ▲ ▼ ▶), או החלקה על המסך בטלפון. רווח עוצר את המשחק.

## איך זה בנוי
- `shared/hub.js` – החשבונות, ההתחברות המשותפת (נשמרת ב-localStorage של הדפדפן), ארנק נפרד לכל משחק (מטבעות, קניות, התקדמות), החנות, כרטיס הסיום, צלילים וקונפטי. כאן גם רשימת המשחקים (`GAMES`) והקטגוריות (`CATS`).
- `shared/hub.css` – העיצוב המשותף, כולל הלוח של משחקי הלוח ולוח הכפתורים של משחקי הפעולה.
- כל משחק הוא קובץ HTML אחד שקורא ל-`Hub.start(...)`: אם אין משתמש מחובר הוא מציג מסך התחברות, ואחרת מתחיל ישר.
- כל משחק אפשר לפתוח גם לבד – הוא יבקש להתחבר עם אותו חשבון.

## הוספת משחק חדש
1. מעתיקים אחד הקבצים ב-`games/` ומשנים את `CFG` (מזהה, שם, פריטי חנות) ואת המשחק עצמו.
2. מוסיפים שורה למערך `GAMES` ב-`shared/hub.js` עם `cat` (think / board / action), ואם רוצים – ציור ב-`art`.

> הסיסמאות נשמרות מגובבות (SHA-256), אבל רק בדפדפן הזה. זו לא אבטחה של שרת אמיתי.
