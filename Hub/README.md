# Mind Studio · סטודיו המשחקים

אפליקציה מאספת ל-30 משחקים. מתחברים פעם אחת בדף הראשי, וכל משחק שנפתח משם כבר מחובר לאותו חשבון.
לכל משחק יש מטבעות, חנות, טבלת שיאים ודו-קרב מול יריבי AI משלו.

| חשיבה | לוח וקלפים | פעולה |
|---|---|---|
| סודוקו חכם (`../Web/index.html`) | שחמט `chess` | כביש מהיר `racer` |
| ציור נסתר `nonogram` | דמקה `checkers` | ריצת הנתיבים `runner` |
| פיצוח הצופן `codebreaker` | ארבעה צבעים `colors` | נחש הכוכבים `snake` |
| גן הפנסים `lights` | ארבע בשורה `connect4` | שובר הלבנים `breakout` |
| זיכרון `memory` | רברסי `reversi` | מגיני הגלקסיה `shooter` |
| מיזוג `merge` | חמש בשורה `gomoku` | כנפיים `wings` |
| שדה מוקשים `mines` | מנקלה `mancala` | מגדל הבלוקים `blocks` |
| מיון צבעים `sort` | צוללות `battleship` | פונג גלקטי `pong` |
| פאזל הזזה `slide` | איקס עיגול על `ultimate` | קפיצה לשמיים `jumper` |
| מגדלים `towers` | 21 `blackjack` | גשם כוכבים `catcher` |

כל המשחקים נמצאים ב-`games/<שם>.html`.

## איך מריצים
```
powershell -ExecutionPolicy Bypass -File Hub\serve.ps1
```
ואז פותחים את http://localhost:8780/Hub/

## איך זה בנוי
- `shared/hub.js` – חשבונות והתחברות משותפת, ארנק לכל משחק, חנות, **רקעים חיים** (גלקסיה, ערפילית, זוהר צפוני, מערכת שמש, בועות, פריחה), **טבלאות שיאים** ו**דו-קרב מול AI** (שלושה יריבים: ניצוץ, אוריון וקוואזר).
- `shared/hub.css` – העיצוב המשותף (כולל כרטיסי זכוכית מעל רקעים כהים).
- `shared/arcade.js` – מנוע למשחקי הפעולה: קנבס, לולאת משחק, חצים/מקלדת/החלקה, עזרים לפני סיבוב, שיאים ודו-קרב "לעקוף את השיא של היריב".
- `shared/duo.js` – מנוע למשחקים מול המחשב: תורות, רמות קושי, תוצאה ודו-קרב ישיר.
- `shared/puzzle.js` – מנוע לפאזלים: שעון, מהלכים, כוכבים ודו-קרב מרוץ (מי פותר ראשון).

## הוספת משחק חדש
1. מעתיקים משחק דומה מ-`games/` (פעולה → arcade, מול המחשב → duo, פאזל → puzzle) ומשנים את `CFG` ואת החוקים.
2. מוסיפים שורה ל-`GAMES` ב-`shared/hub.js` עם `cat` (think / board / action) ו-`emo` לציור הכריכה.

> הכול נשמר בדפדפן הזה בלבד (כולל טבלאות השיאים). הסיסמאות מגובבות, אבל זו לא אבטחה של שרת אמיתי.
